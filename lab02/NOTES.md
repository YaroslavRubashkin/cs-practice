Разница между Git  и GitHub: Git - локальная система контроля версий на пк, а GitHub - это облачный хостинг для удаленного хранения репозитивов
Сравнение состояний: команда git diff сравнивает рабочую область с индексом, а git diff --staged сравнивает индекс с последним коммитом.

git status - показывает состояние файлов.
git diff - показывает изменения до индексации.
git diff --staged  - показывает изменения в индексе.

Ветки: Ветка - это указатель на коммит, позволяющий вести независимую разработку. При создании коммита указатель ветки автоматически сдвигается вперед. Слияние объединяет историю нескольких веток в одну.
