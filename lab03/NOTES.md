#Лабораторная работа 3

Разница между git diff, git show, git log
- git diff показывает разницу между различными состояниями файлов.
- git show показывает полную информацию и изменения конткретного одного коммита.
- git log показывает общую историю всех коммитов без детального кода.

Что нашли команды log -S и blame:
- git log -S ищет коммиты, в которых количество упоминаний заданной строки изменилось.
- git blame показывает построчно автора и коммит для каждого изменения в файле.

Восстановление файлов:
- git restore восстанавливает файл в рабочей директории из индекса или последнего коммита, отменяя локальные незакоммиченные правки.
- git restor --source=HEAD~2 восстанавливает состояние файла, каким оно было два коммита назад.
- Если локальные правки были добавлены в индекс (git add), обычный git restore  без флагов сбросил бы изменения только до состояния в индексе. Чтобы отчистить в индекс, нужно использовать git restore --staged
